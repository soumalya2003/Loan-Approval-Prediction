# Loan Approval Prediction

**Author:** Soumalya Pal  
**Program:** Data Science & Business Analytics / Machine Learning  
**Project type:** Machine Learning

## Overview
A classification project to predict loan approval outcomes using applicant financial, credit, education, and asset-related information.

## Objectives
- Inspect and understand the dataset.
- Prepare data for machine learning.
- Train and compare suitable models.
- Evaluate model performance using appropriate metrics.
- Interpret the results and document limitations.

## Workflow and Key Features
Data inspection, 12 exploratory visualizations, missing-value handling, scaling and one-hot encoding through preprocessing pipelines, model comparison, confusion matrix, ROC curves, and Random Forest feature importance.

## Models
Logistic Regression, Decision Tree Classifier, Random Forest Classifier, and Support Vector Machine (SVM)

## Evaluation
Accuracy, Precision, Recall, F1-score, and ROC-AUC

> Results should be taken from the executed notebook. No performance figures are claimed in this README unless they are verified from the notebook output.

## Technologies
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn (where used)
- Scikit-learn

Expected dataset: `loan_approval_dataset.csv`

**Important:** Place the required CSV dataset in this project folder before running the notebook. The dataset is not included in this package. Make sure you have permission to redistribute any dataset before uploading it to a public repository.

## How to Run
1. Download or clone this repository.
2. Install Python and Jupyter Notebook, or open the notebook in Google Colab.
3. Install the libraries used in the notebook if they are not already available.
4. Add the required dataset in the location expected by the notebook.
5. Open `loan_approval_prediction.ipynb` and run the cells from top to bottom.

Typical packages used in these projects:
```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

## Limitations
Model performance depends on the dataset, preprocessing choices, and evaluation split. Predictions are for educational and portfolio purposes and should not be treated as professional financial, property, or admissions advice.
